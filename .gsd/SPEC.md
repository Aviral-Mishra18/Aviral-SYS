# SPEC.md — Project Specification: Aviral Cyber Portfolio

> **Status**: `DEVELOPMENT`
>
> ⚠️ **Planning Lock**: Active.

## Vision
A high-end, futuristic cyberpunk developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and GSAP. The application functions as a "digital system interface" with cinematic animations and a premium glassmorphism aesthetic.

## Goals
1. **Premium Aesthetic** — Dark theme with neon accents and high-quality animations.
2. **Interactive UI** — Responsive sections that feel like a live OS.
3. **Core Sections** — Initialize (Hero), About.exe, Projects Lab, Skills Matrix, and Contact Channel.
4. **Performance** — Fast load times and smooth framerates (60 FPS+).

## Tech Stack
- **Framework**: React 19 (Vite)
- **Styling**: Tailwind CSS 4.0
- **Animations**: Framer Motion & GSAP
- **Icons**: Lucide React

## Success Criteria
- [ ] Fully responsive HERO section with active navigation.
- [ ] Projects showcase with interactive hover states.
- [ ] Smooth scroll-triggered animations across all sections.
- [ ] Integrated GSD methodology for continued development.
